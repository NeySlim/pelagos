# Adding a language

A language is a folder of `frontend/src/i18n/locales/`. The code is its
[BCP 47](https://www.rfc-editor.org/info/bcp47) tag (`de`, `pt-BR`); the name
shown in the user menu comes from the browser (`Intl.DisplayNames`), in that
language.

1. Copy `locales/en/` to `locales/<code>/` and translate the values. Keep the
   keys, the `{{placeholders}}` and the plural suffixes (`_one`, `_other`).
   No em dashes, no empty values.
2. `cd frontend && npx vitest run src/i18n`: `i18n.test.js` fails for any
   folder, even an empty one, and lists every missing file and key.
3. `make notify-catalogs` writes `backend/pelagos/data/i18n/<code>.json` (the
   notification texts); commit it. `test_packaged_catalogs_match_the_frontend`
   and `test_languages_follow_the_locale_folders` fail until it is done.
4. Backend texts come with message keys (`messages.json`): a key missing in
   the new language shows the English text.

Not derived from the folders yet: the allowed values of the account
`language` preference and of a notification channel's `language` still list
`en` and `fr` in the backend.
