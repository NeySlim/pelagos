# age test vectors (CCTV)

Copied from https://github.com/C2SP/CCTV/tree/main/age/testdata at commit
`50a8ecf2a220f4c8bdc4f085789b8e85c26829e7` (fetched 2026-10-28), the test kit
that https://age-encryption.org/testkit points to. Only the vectors for binary
files and X25519 identities are kept: Pelagos implements neither the ASCII
armor nor the scrypt and ML-KEM recipient types.

License of the vectors: 0BSD, CC0 1.0 or Unlicense, at the user's choice
(see the CCTV age README).
