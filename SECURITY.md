# Security policy

## Reporting a vulnerability

Do not open a public issue. Report it through GitHub private vulnerability
reporting: the "Report a vulnerability" button on the repository's
Security tab (`https://github.com/NeySlim/pelagos/security/advisories/new`).

Include the version (`pelagos version`), the platform (deb, rpm or
container), what an attacker needs (network access, a role, a local
account) and the steps to reproduce.
The fix and the advisory are published together.

## Supported versions

Only the latest release gets security fixes.
